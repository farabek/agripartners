# AgriPartners NEAR Execution Phase 1

## Purpose

This folder converts the existing NEAR documentation into a practical Phase 1 execution plan. It defines target categories, engagement objectives, outreach sequence, and success metrics for structured ecosystem outreach.

Phase 1 is documentation-only planning. It does not include personal names, contact research, direct outreach, commits, pushes, frontend changes, backend changes, contract changes, or test changes.

## Phase 1 Scope

Phase 1 is focused on preparation and controlled ecosystem engagement.

The work should stay category-based and program-level. It should not identify individual people, scrape contacts, or create private outreach lists.

## Operating Principle

The goal is to present AgriPartners as a working Alpha v1 MVP with NEAR Testnet validation, then collect ecosystem feedback, validate positioning, request introductions, explore partnerships, and improve project visibility.
