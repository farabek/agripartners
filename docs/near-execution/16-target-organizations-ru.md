# Target Organizations

## Purpose

Этот документ переводит Phase 1 category-level planning в Phase 2 organization-level planning. Он остается на уровне organization categories и не включает personal names, email addresses, phone numbers или contact research.

## Priority 1

Priority 1 organization categories наиболее важны для ecosystem credibility, strategic alignment и early validation.

### Foundation-related organizations

#### Why it matters

Foundation-related organizations могут помочь AgriPartners понять ecosystem priorities, grant expectations, RWA relevance и readiness standards для серьезного NEAR ecosystem engagement.

#### What AgriPartners wants

AgriPartners хочет получить feedback по ecosystem fit, ясности NEAR use case, grant readiness, audit and mainnet expectations, а также понять, достаточно ли сильна Alpha v1 story для deeper review.

#### Which materials to send first

Сначала отправьте intro message, затем project summary, если есть интерес.

Рекомендуемые первые материалы:

- `docs/near-outreach-toolkit/12-intro-message-ru.md`
- `docs/near-outreach/12-project-summary-ru.md`
- `docs/near-outreach/15-near-use-case-ru.md`

#### Expected outcome

Expected outcomes включают strategic feedback, подтверждение ecosystem fit, guidance по grant или program readiness, а также возможные program-level introductions.

### Ecosystem leadership organizations

#### Why it matters

Ecosystem leadership organizations могут помочь проверить, насколько AgriPartners релевантен broader NEAR priorities, builder growth, RWA narratives и partner development.

#### What AgriPartners wants

AgriPartners хочет validation of positioning, guidance по лучшему ecosystem path, introductions к релевантным program categories и feedback о том, как responsibly представлять проект.

#### Which materials to send first

Сначала отправьте concise intro, затем project summary и ecosystem one-pager.

Рекомендуемые первые материалы:

- `docs/near-outreach-toolkit/12-intro-message-ru.md`
- `docs/near-outreach/12-project-summary-ru.md`
- `docs/near-outreach/16-ecosystem-one-pager-ru.md`

#### Expected outcome

Expected outcomes включают ecosystem guidance, category-level introductions, visibility opportunities и более ясные next steps для Phase 2 execution.
