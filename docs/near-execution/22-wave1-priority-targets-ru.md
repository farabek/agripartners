## Target Notes

### 1. NEAR Horizon

Recommended positioning:

AgriPartners - founder-ready NEAR testnet startup demo, который объединяет agricultural RWA finance с wallet-based identity, portfolio analytics, funding progress и smart-contract interaction.

Best first ask:

- "Which NEAR Horizon pathway or founder resource is most relevant for a working agricultural RWA demo at Alpha v1?"

Primary material:

- `docs/presentation-readiness/01-executive-summary.md`
- `docs/presentation-readiness/02-demo-flow.md`
- `docs/presentation-readiness/05-near-use-case.md`
- `docs/presentation-readiness/07-investor-one-pager.md`

### 2. NEAR DevHub

Recommended positioning:

AgriPartners нужен technical feedback до любых mainnet claims. Ask должен быть про developer feedback, testnet architecture, wallet UX, smart contract boundaries и grant/tooling direction.

Best first ask:

- "Could this testnet workflow be reviewed for NEAR technical fit and mainnet-readiness gaps?"

Primary material:

- `docs/presentation-readiness/05-near-use-case.md`
- `docs/presentation-readiness/06-demo-script.md`
- GitHub repository link.
- Demo walkthrough link when available.

### 3. NEAR Foundation

Recommended positioning:

AgriPartners - concrete RWA use case on NEAR, который показывает, как blockchain может поддержать agriculture finance через wallet access, contract-linked workflow, reporting и verification.

Best first ask:

- "Does this use case fit current NEAR ecosystem priorities, and where should it be routed for feedback or program review?"

Primary material:

- Executive Summary.
- NEAR Use Case.
- Platform Metrics.
- Screenshot Pack.

### 4. Outlier Ventures - RWA Base Camp

Recommended positioning:

AgriPartners - early RWA startup, который переводит agricultural investment из documents и offline trust в digital workflow для funding, reports, portfolio visibility и verification.

Best first ask:

- "Is this RWA framing strong enough for accelerator review, and what gaps should be fixed before applying?"

Primary material:

- Investor One Pager.
- Demo Script.
- Platform Metrics.
- Demo Walkthrough.

### 5. Hub71+ Digital Assets

Recommended positioning:

AgriPartners соединяет Web3 infrastructure с agriculture, food security и MENA capital discovery. Сильнейший angle - не только crypto, а regional agricultural finance с transparent digital infrastructure.

Best first ask:

- "Would this fit a digital-assets startup pathway in Abu Dhabi, and what regional validation would be needed?"

Primary material:

- Investor One Pager.
- Executive Summary.
- Screenshot Pack.
- Demo Flow.
