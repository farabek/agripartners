# Outreach Messages

This document provides reusable Wave 1 outreach templates for AgriPartners Validation Phase.

Use these as starting points only. Before sending, customize the target name, current program/contact path, demo link, GitHub link, and one specific ask.

- Investor One Pager.

Subject: Feedback request: AgriPartners agricultural RWA workflow on NEAR

Hello,

I am preparing Wave 1 validation for AgriPartners Alpha v1 and would value NEAR ecosystem feedback.

It includes NEAR wallet authentication, investor and farmer portals, smart-contract-linked deal views, funding progress, portfolio analytics, farmer reporting, ROI/returns visibility, and a testnet withdrawal flow.
