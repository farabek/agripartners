# Wave 1 Outreach Tracking

## Purpose

This document provides a simple tracking system for NEAR Wave 1 outreach.

Wave 1 is focused on ecosystem feedback. The tracking system should help AgriPartners understand who has been approached by organization category, what materials were sent, what feedback was received, and what next action is required.

This document is a template only. It does not include contacts, personal names, contact research, outreach activity, commits, pushes, or implementation changes.

## Outreach Pipeline

Use the following pipeline statuses for every outreach item.

### Planned

The organization category has been identified, but no message has been sent.

Use when:

- The target fits Wave 1 goals.
- Materials still need to be prepared.
- The outreach order is not finalized.

### Contacted

An initial message has been sent.

Use when:

- The intro message was sent.
- The project has not yet received a response.
- No meeting or follow-up has been confirmed.

### Replied

The organization has responded.

Use when:

- A response was received.
- The response needs review.
- The next step is not yet confirmed.

### Meeting Scheduled

A feedback call or review meeting has been scheduled.

Use when:

- A meeting time is confirmed.
- Materials need to be prepared before the meeting.
- Questions or agenda items should be listed.

### Feedback Received

Useful feedback has been collected.

Use when:

- Feedback has been captured in the tracking table.
- Material updates, product notes, or technical questions were identified.
- The conversation has a clear outcome.

### Follow-up Required

The next step depends on AgriPartners sending additional context, clarification, or updated materials.

Use when:

- A reviewer requested more information.
- A response needs to be sent after a meeting.
- A conversation has gone quiet but still has potential value.

### Partnership Discussion

The conversation has moved beyond general feedback into a possible collaboration path.

Use when:

- The organization category may support ecosystem, technical, regional, accelerator, or investor pathways.
- A partnership idea needs structured review.
- The next action should define scope, value, and readiness.

## Field Guidance

### Date

Use the date of the latest meaningful action.

### Organization

Use organization names only when they are already known through existing planning or direct user-provided context. Do not conduct contact research.

### Category

Recommended categories:

- Ecosystem.
- Accelerator.
- Technical.
- Regional.
- Investor.
- Community.
- Program.

### Status

Use one of the pipeline statuses:

- Planned.
- Contacted.
- Replied.
- Meeting Scheduled.
- Feedback Received.
- Follow-up Required.
- Partnership Discussion.

### Materials Sent

List only the materials actually sent or planned for that row.

Recommended material labels:

- Intro message.
- Project summary.
- NEAR use case.
- Ecosystem one-pager.
- Investor deck.
- Demo script.
- Product screenshots.

### Feedback

Capture short, practical feedback.

Useful feedback types:

- Positioning feedback.
- NEAR relevance feedback.
- Technical question.
- Accelerator readiness note.
- Partnership fit note.
- Material improvement request.
- Mainnet readiness concern.

### Next Action

Define one concrete next action.

Examples:

- Send project summary.
- Schedule feedback call.
- Prepare technical notes.
- Update NEAR use case.
- Send follow-up.
- Move to partnership review.
- Close as low fit.

### Owner

Use a role or internal owner label. Personal names are not required for this template.

Examples:

- Founder.
- Product.
- Technical.
- Partnerships.
- Operations.

## Success Metrics

Wave 1 success should be measured by useful signal, not by volume alone.

Minimum Phase 3 Wave 1 targets:

- 10 meaningful ecosystem or program conversations.
- 3 accelerator discussions.
- 2 partnership discussions.
- 1 application submitted.

## Review Rules

- Keep tracking at organization and category level.
- Do not add personal names unless explicitly required by the user later.
- Do not research contacts from this template.
- Do not count a message as a conversation unless there is a meaningful reply or meeting.
- Do not count a partnership discussion until there is a clear collaboration topic.
- Update feedback in concise operational language.
- Keep next actions specific and dated where possible.
