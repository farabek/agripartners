# Engagement Objectives

## Purpose

This document defines what AgriPartners should try to achieve during Phase 1 NEAR ecosystem engagement.

## Feedback

Collect clear feedback on whether the AgriPartners story, product status, NEAR use case, and Alpha v1 scope are understandable.

Useful feedback areas:

- Clarity of the agricultural investment workflow.
- Clarity of NEAR's role in the product.
- Strength of the Alpha v1 demonstration.
- Missing information needed by ecosystem reviewers.

## Validation

Validate whether AgriPartners is positioned credibly as a working Alpha v1 MVP using NEAR Testnet infrastructure.

Validation should focus on:

- Ecosystem fit.
- RWA relevance.
- Grant or program readiness.
- Mainnet readiness assumptions.
- Pilot credibility.

## Introductions

Request category-level introductions only when the project story is clear and the recipient has enough context.

Useful introduction types:

- Program-level introductions.
- Technical review introductions.
- Ecosystem partner introductions.
- Founder support introductions.

## Partnerships

Explore whether any ecosystem or regional partner categories are relevant for pilots, technical validation, grant pathways, or visibility.

Partnership discussions should remain exploratory during Phase 1.

## Visibility

Increase ecosystem awareness of AgriPartners in a controlled way.

Visibility should come from clear materials, responsible positioning, and useful conversations rather than broad unsolicited outreach.

## Phase 1 Guardrails

- Present the project as Alpha v1.
- Avoid production investment claims.
- Avoid personal names and contact lists.
- Keep outreach category-based.
- Use existing NEAR documentation as the source of truth.
