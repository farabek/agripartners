## Core Positioning

AgriPartners is a working Alpha v1 MVP for transparent agricultural investment workflows on NEAR Testnet. It combines investor, farmer, and admin portals with contract-aware lifecycle tracking for pilot livestock projects in Central Asia.

The current outreach position is:

> A working alpha that demonstrates how agricultural pilot investments can be structured, reported, tracked, and validated using NEAR-based infrastructure.
