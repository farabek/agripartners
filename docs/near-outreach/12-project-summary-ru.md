# AgriPartners: краткое описание проекта

## Что такое AgriPartners

AgriPartners - это платформа для прозрачных инвестиционных процессов в сельском хозяйстве на базе NEAR. Она помогает инвесторам оценивать пилотные агропроекты, фермерам - отчитываться о ходе работы, а партнерам - отслеживать жизненный цикл сделок через отдельные роли и кабинеты.

Текущий продукт - Alpha v1 MVP с кабинетом инвестора, кабинетом фермера, админ-панелью, backend API и интеграцией с NEAR Testnet.

## Проблема

Сельскохозяйственным операторам часто нужен оборотный капитал до того, как проект начнет приносить выручку. Инвесторам при этом нужна понятная видимость экономики проекта, операционного прогресса, отчетности и статуса возвратов.

Во многих развивающихся аграрных рынках инвестиционные сделки все еще ведутся через бумажные договоренности, офлайн-отчеты, неформальную коммуникацию и разрозненные записи. Это снижает прозрачность, усложняет контроль и мешает внешнему капиталу заходить в такие проекты.

## Решение

AgriPartners переводит агроинвестиционные процессы в структурированный цифровой workflow:

- Инвесторы видят портфельные метрики, пилотные сделки, ROI, ожидаемые возвраты, уже возвращенные суммы и outstanding amount.
- Фермеры видят подтверждение финансирования, прогресс циклов, активные сделки, завершенные сделки и статус отчетности.
- Администраторы контролируют сделки, отчеты, статусы возвратов и историю событий.
- NEAR Testnet поддерживает wallet-authenticated доступ и contract-aware события жизненного цикла.

Цель продукта - сделать агрофинансирование более понятным для оценки, мониторинга и доверия.

## Почему сельское хозяйство

Сельское хозяйство - это реальный сектор, где нехватка оборотного капитала напрямую ограничивает производство. У фермеров и операторов может быть сильная экспертиза и рыночный спрос, но не хватать структурированного финансирования.

AgriPartners начинает с животноводства, потому что такие проекты можно описывать через понятные входные данные, производственные циклы, отчетные точки, продажи и расчет возвратов.

## Почему Центральная Азия

В Центральной Азии сильные аграрные традиции, активные рынки животноводства и большое количество операторов, которые до сих пор зависят от relationship-based финансирования. При этом есть разрыв между локальными агровозможностями и капиталом, которому нужны прозрачность и структурированность.

AgriPartners помогает превращать локальные агропроекты в прозрачные и проверяемые инвестиционные процессы, понятные региональным и международным партнерам.

## Почему блокчейн

Блокчейн полезен здесь потому, что агроинвестиционным сделкам нужны прозрачность, фиксация состояния и проверяемая история. NEAR smart contracts могут отражать условия сделки, статус финансирования, переходы жизненного цикла, отчетные события и settlement-related действия.

Идея не в том, чтобы использовать блокчейн ради блокчейна. Идея в том, чтобы создать trust layer для агроинвестиционных процессов, которые сейчас слишком ручные и непрозрачные.

## Текущий статус MVP

AgriPartners Alpha v1 готов к controlled external demonstrations.

Текущие компоненты MVP:

- Investor Dashboard с портфельными метриками.
- Farmer Portal с видимостью финансирования, циклов и отчетности.
- Admin Dashboard для операционного мониторинга.
- Backend API для сделок, пользователей, отчетности и событий.
- Презентация пилотных сделок Fidlot Livestock Project и Hissar Sheep Breeding Project.
- Investor package и investor deck на английском и русском языках.

MVP следует позиционировать как working alpha, а не как production investment platform.

## Текущий статус NEAR Testnet

AgriPartners использует NEAR Testnet для демонстрации wallet-authenticated доступа, contract-backed deal flows и transaction-oriented операций по проектам.

Текущая Testnet-валидация включает:

- Contract-aware концепции жизненного цикла сделки.
- Wallet-based role access для investor, farmer и admin views.
- Funding confirmation, cycle activation, farmer reporting, return recording и lifecycle status events.
- Demo workflow для активных и завершенных пилотных проектов.

Mainnet launch зависит от security audit, legal readiness и partner validation.
