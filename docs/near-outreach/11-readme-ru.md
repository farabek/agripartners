## Core Positioning

AgriPartners - это рабочий Alpha v1 MVP для прозрачных процессов агроинвестиций на NEAR Testnet. Он объединяет порталы инвестора, фермера и администратора с учетом контрактного жизненного цикла пилотных животноводческих проектов в Центральной Азии.

Текущая позиция для внешних коммуникаций:

> Рабочая alpha-версия, показывающая, как пилотные агроинвестиции можно структурировать, документировать, отслеживать и подтверждать с помощью инфраструктуры на базе NEAR.

## Status Notes

- Статус MVP: Alpha v1, готова для контролируемых внешних демонстраций.
- Статус NEAR: проверка workflow в Testnet активна; запуск в mainnet ожидает аудита безопасности, юридической готовности и проверки с партнерами.
- Пилотные проекты: Fidlot Livestock Project и Hissar Sheep Breeding Project.
- Объем: только документация для outreach. Этот пакет не меняет frontend, backend, contracts, tests, deployment или git history.
