# Founder Introduction

## Founder

Farhod Muhamadiev is the founder of AgriPartners.

## Background

Farhod is a full-stack builder with direct exposure to agricultural opportunities in Central Asia and the practical financing gaps that farmers face. He built the current AgriPartners Alpha v1 platform across the core stack:

- NEAR smart contract workflow.
- Backend API.
- Role-based authentication.
- Investor, farmer, and admin portals.
- Pilot deal presentation and investor documentation.

This founder-led build gives AgriPartners a practical, product-first foundation. The current MVP is not just a concept deck; it is a working alpha that can be demonstrated to investors, partners, and the NEAR ecosystem.

## Vision

Farhod's vision is to make agricultural investment more transparent, structured, and accessible. Many agricultural projects are real, productive, and financeable, but they are not packaged in a way that external investors can review with confidence.

AgriPartners aims to bridge that gap by turning relationship-heavy agricultural finance into a digital workflow where project terms, funding, reporting, lifecycle events, and returns are easier to track and verify.

## Why AgriPartners

AgriPartners was created because farmers need better access to working capital, while investors need better visibility and trust.

The project starts with livestock pilots because these deals have clear production cycles, measurable milestones, and practical regional relevance. Over time, the same workflow can support additional agricultural models, partner programs, and real-world asset use cases.

For the NEAR ecosystem, AgriPartners is a practical example of blockchain infrastructure serving real-sector economic activity rather than speculative trading.
