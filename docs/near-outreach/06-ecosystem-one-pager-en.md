# AgriPartners Ecosystem One Pager

## One-Liner

AgriPartners is a working Alpha v1 MVP that uses NEAR Testnet to demonstrate transparent agricultural investment workflows for livestock projects in Central Asia.

## What It Does

AgriPartners helps agricultural investment stakeholders work from one structured workflow:

- Investors review pilot deals, ROI, APR, expected returns, returned amount, and outstanding amount.
- Farmers track funding, cycles, active deals, completed deals, and reporting status.
- Admins monitor reporting, repayment status, deal events, and lifecycle progress.
- NEAR Testnet supports wallet-authenticated, contract-aware workflow validation.

## Why It Matters

Agricultural finance in emerging markets is often relationship-heavy, paper-based, and difficult for external investors to monitor. AgriPartners makes these workflows more transparent, structured, and reviewable.

For the NEAR ecosystem, the project is a real-world asset use case focused on productive economic activity: livestock financing, farmer reporting, investor visibility, and transparent lifecycle tracking.

## Pilot Projects

### Fidlot Livestock Project

- Model: Livestock fattening.
- Status: Completed pilot presentation.
- Investment: $50,000.
- ROI: 64%.
- APR: 21.9%.
- Cycles: 7.
- Returned: $82,000.

### Hissar Sheep Breeding Project

- Model: Sheep breeding.
- Status: Active pilot presentation.
- Investment: $50,000.
- Projected ROI: 63.3%.
- APR: 21.1%.
- Cycles: 6.
- Outstanding expected returns: $81,672.

Across both pilots, the demo portfolio represents $100,000 in total pilot funding and $163,672 in expected returns.
