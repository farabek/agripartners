# AgriPartners: one pager для ecosystem partners

## One-liner

AgriPartners - это working Alpha v1 MVP, который использует NEAR Testnet для демонстрации прозрачных агроинвестиционных workflows для livestock projects в Центральной Азии.

## Что делает продукт

AgriPartners помогает участникам агроинвестиций работать через один структурированный workflow:

- Investors оценивают pilot deals, ROI, APR, expected returns, returned amount и outstanding amount.
- Farmers отслеживают funding, cycles, active deals, completed deals и reporting status.
- Admins контролируют reporting, repayment status, deal events и lifecycle progress.
- NEAR Testnet поддерживает wallet-authenticated и contract-aware workflow validation.

## Почему это важно

Агрофинансирование в emerging markets часто остается relationship-heavy, paper-based и сложным для мониторинга внешними инвесторами. AgriPartners делает такие процессы более прозрачными, структурированными и проверяемыми.

Для NEAR ecosystem проект является real-world asset use case, связанным с продуктивной экономической активностью: livestock financing, farmer reporting, investor visibility и transparent lifecycle tracking.

Status: Alpha v1, ready for controlled external demonstrations.

## Pilot projects

- Model: Livestock fattening.
- Status: Completed pilot presentation.
- Investment: $50,000.
- ROI: 64%.
- APR: 21.9%.
- Cycles: 7.
- Returned: $82,000.

### Hissar Sheep Breeding Project

- Model: Sheep breeding.
- Status: Active pilot presentation.
- Investment: $50,000.
- Projected ROI: 63.3%.

- Cycles: 6.

## NEAR fit

AgriPartners использует NEAR как auditable workflow и trust layer:

- Wallet-authenticated role access.
- Contract-aware lifecycle events.
- Потенциал low-cost repeated transactions.
- Readable account experience для non-crypto users.
- RWA и emerging-market relevance.
