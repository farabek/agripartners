# Outreach Playbook

This playbook supports founder-led outreach for AgriPartners Alpha v1.2 across NEAR ecosystem contacts, technical reviewers, pilot partners, and strategic conversations.

## Positioning

AgriPartners is an open-source Alpha v1.2 platform on NEAR Testnet for transparent agricultural investment workflows.

The platform brings investor, farmer, and admin workflows into one role-based operating environment, with treasury visibility, Treasury Shadow Accounting, Presentation Mode, wallet authentication, and NEAR Testnet integration.

## Outreach Goals

- Build awareness inside the NEAR ecosystem.
- Get technical feedback on Alpha v1.2.
- Identify pilot partner interest.
- Start strategic conversations around AgriTech, RWA, and transparent agricultural finance workflows.
- Improve demo readiness and documentation based on real external feedback.

## Audience Segments

### NEAR Ecosystem

Primary ask: ecosystem fit feedback and introductions.

Useful angle: practical RWA and AgriTech workflow exploration on NEAR Testnet.

### Technical Builders

Primary ask: code, architecture, Testnet, and workflow review.

Useful angle: open-source Alpha platform with role-based workflows and Treasury Shadow Accounting.

### Pilot Partners

Primary ask: workflow validation and pilot readiness discussion.

Useful angle: transparent operating layer for agricultural opportunity review, farmer updates, and treasury visibility.

### Investor / Strategic Partners

Primary ask: strategic conversation and feedback.

Useful angle: long-term infrastructure for trusted agricultural investment workflows.

## Messaging Principles

- Lead with the problem and workflow, not the technology alone.
- Be clear that the product is Alpha v1.2 on NEAR Testnet.
- Ask for feedback before asking for support.
- Keep messages short and specific.
- Avoid hype, token speculation, guaranteed return language, or production claims.

## Recommended Outreach Sequence

1. Connect on LinkedIn or send a short introduction.
2. After acceptance, send a concise context message.
3. Share the GitHub repository or relevant one-pager only when useful.
4. Ask for a short feedback conversation.
5. Log the contact, response, and next step in the CRM.
6. Follow up once after 5-7 days if there is no response.

## Core Assets

- Founder LinkedIn profile.
- GitHub repository.
- Executive One Pager.
- NEAR One Pager.
- Investor One Pager.
- Presentation Mode or demo link when stable.

## Follow-Up Rules

- Follow up once with new context or a clearer ask.
- Do not pressure contacts.
- Close inactive threads respectfully.
- Capture useful objections and questions as product feedback.
