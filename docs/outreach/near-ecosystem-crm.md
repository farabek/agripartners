Preferred asks:

- Short feedback conversation.
- Technical review.
- NEAR ecosystem fit discussion.
- Pilot workflow discussion.
- Strategic introduction.

Avoid:

- Direct fundraising language.
- Production investment claims.
- Mainnet, custody, payout, settlement, or guaranteed return language.
