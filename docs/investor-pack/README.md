- Strategic partners.
- NEAR ecosystem reviewers.

- `investor-brief.md` - Professional investor brief for AgriPartners Alpha v1.

## Scope

This pack is documentation only. It does not include code, frontend changes, backend changes, commits, or pushes.

All claims should remain grounded in the current AgriPartners Alpha v1 implementation, existing documentation, current demo modules, NEAR Testnet workflows, and current pilot demonstration profiles.

The pack should not claim:

- Production deployment.
- Audited smart contracts.
- Live mainnet operations.
- Completed functionality beyond the verified Alpha v1 scope.
