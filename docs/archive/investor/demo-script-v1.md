# AgriPartners Demo Script v1

## Setup
Open the AgriPartners Alpha v1 investor dashboard with a prepared investor account.

## 1. Introduce the Platform
AgriPartners is an agricultural investment workflow platform designed to make pilot deal economics, operational progress, and returns easier for investors to understand.

## 2. Show Investment Summary
Point out the dashboard summary:
- Total Invested
- Expected Returns
- Returned
- Outstanding
- Average ROI
- Active Deals
- Completed Deals

## 3. Show Featured Pilot Deals
Open with the two real pilot models:
- Fidlot Livestock Project: $50,000, 64% ROI, 21.9% simple annualized ROI, 7 cycles.
- Hissar Sheep Breeding Project: $50,000, 63.3% projected ROI, 21.1% simple annualized ROI, 6 cycles.

## 4. Open a Project Profile
Open the Fidlot project detail page.

Explain that the investor sees the project name, investment size, profitability, cycles, status, and pilot origin before technical deal data.

## 5. Show Reporting and Returns
Scroll through:
- Investment Summary
- Reports
- Returns
- ROI
- Event History

## 6. Explain NEAR Testnet Role
Position NEAR Testnet as the demonstration layer for transparent workflow validation and future blockchain-based settlement readiness.

## 7. Close
AgriPartners Alpha v1 is ready for investor feedback, ecosystem review, and pilot expansion planning.
