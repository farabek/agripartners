# AgriPartners Documentation Archive

Status: Living archive manifest

Owner: Operations

## Purpose

The archive preserves historical, deprecated, superseded, and non-authoritative
AgriPartners materials without deleting their context or Git history. Archived files
must not be used as current Product, Business, Legal, Investor, Pilot, NEAR, or
operational authority.

Canonical and active documents remain outside `docs/archive/`. Use the
[Documentation Index](../DOCUMENTATION_INDEX.md) to find current documentation and
the [Documentation Authority Matrix](../DOCUMENTATION_AUTHORITY_MATRIX.md) to verify
authority.

## Archive Rules

- Preserve Git history with `git mv`.
- Record every archive batch in a pre-move manifest.
- Update identified local links in the same batch.
- Do not move canonical or stable-path documents through a routine archive operation.
- Do not delete archived files solely because they are obsolete.
- Treat archived claims, agreements, screenshots, models, and outreach records as
  historical.
