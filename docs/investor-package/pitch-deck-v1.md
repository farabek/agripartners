# AgriPartners Investor Pitch Deck v1

## 1. Cover
AgriPartners Alpha v1

Agricultural investment workflows demonstrated on NEAR Testnet.

## 2. Problem
Agricultural operators need transparent working capital, while investors need clearer reporting, structured returns, and verifiable deal execution.

## 3. Solution
AgriPartners connects investors and farmers through project-based investment workflows with dashboard visibility, cycle reporting, and return tracking.

## 4. Pilot Deals
- Fidlot Livestock Project: $50,000 investment, 64% ROI, 21.9% APR, 7 cycles.
- Hissar Sheep Breeding Project: $50,000 investment, 63.3% ROI, 21.1% APR, 6 cycles.

## 5. Product Demo
Investor dashboard highlights investment summary, featured pilot deals, active deals, completed deals, project profiles, reports, returns, and event history.

## 6. NEAR Value
The alpha demonstrates how agricultural finance workflows can use NEAR Testnet for transparent transaction and workflow validation.

## 7. Investor Value
Investors can review project economics, understand deal status, and follow operational reporting before reviewing technical details.

## 8. Roadmap
- Alpha v1 investor demonstrations.
- Pilot partner validation.
- Expanded demo portfolio.
- Mainnet readiness planning.

## 9. Ask
Seeking strategic investors, ecosystem partners, and pilot collaborators for agricultural finance deployment.
