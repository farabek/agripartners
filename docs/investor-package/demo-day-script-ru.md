# AgriPartners: demo day script

Длительность: 5-7 минут.

Flow: Investor -> Farmer -> Admin -> NEAR Testnet -> Investment Ask.

## 0:00-0:45 - Вступление

Здравствуйте, я представляю AgriPartners Alpha v1.

AgriPartners - это agricultural investment workflow platform. Мы помогаем инвесторам оценивать экономику пилотных сделок, отслеживать операционный прогресс, видеть возвраты и валидировать активность проекта через понятный цифровой интерфейс.

Первая демонстрация сфокусирована на двух пилотных агромоделях:

- Fidlot Livestock Project - завершенный livestock fattening pilot.
- Hissar Sheep Breeding Project - активный sheep breeding pilot.

Вместе эти пилоты представляют $100,000 total pilot funding и $163,650 expected returns.

## 0:45-2:15 - Investor Portal

Начнем с investor view, потому что инвестору нужна ясность с первых секунд.

В Investor Dashboard инвестор видит портфельные метрики: total invested capital, expected returns, returned amount, outstanding amount, active deals, completed deals и ROI.

Текущий pilot portfolio показывает:

- $100,000 total pilot funding.
- $163,650 expected returns.
- $82,000 returned.
- Одну активную и одну завершенную сделку.

Далее показываем Featured Pilot Deals. Fidlot - завершенный livestock project с $50,000 invested, 64% ROI, 21.9% APR и 7 cycles. Hissar - активный sheep breeding project с $50,000 invested, 63.3% projected ROI, 21.1% APR и 6 cycles.

Главное: инвестор может сравнить агропроекты в привычном инвестиционном формате до погружения в технические детали.

## 2:15-3:15 - Farmer Portal

Теперь переходим в Farmer Portal.

Фермер видит практичный операционный интерфейс: funding confirmation, active and completed deals, cycle progress и reporting status.

По Fidlot проект завершен, отчет отправлен. По Hissar проект активен, первый цикл идет, следующий отчет ожидается.

Этот интерфейс важен, потому что доверие инвестора зависит от дисциплины отчетности. AgriPartners не просто показывает инвестиционные карточки; платформа структурирует операционное поведение за этими карточками.

## 3:15-4:25 - Admin Dashboard

Далее показываем Admin Dashboard.

Admin view дает контролируемый мониторинг пилотного портфеля. Администратор видит статус проекта, funding, ROI или projected ROI, APR, farmer reporting status, return status и event history.

По текущим пилотам admin metrics показывают $100,000 total pilot funding, $82,000 returned и $81,650 outstanding. Fidlot завершен с return recorded. Hissar активен, возвраты pending.

Этот слой важен для акселераторов, фондов и стратегических инвесторов, потому что пилотное агрофинансирование требует операционного контроля до масштабирования.

## 4:25-5:30 - NEAR Testnet

Теперь переходим к NEAR Testnet layer.

AgriPartners использует NEAR Testnet для демонстрации wallet-authenticated access, contract-aware workflows и transparent lifecycle events.

Главное - не заставлять инвестора думать о blockchain complexity. Главное - trust infrastructure. NEAR может поддерживать project workflow validation, event references и future settlement readiness за понятным investor-friendly интерфейсом.

В текущей Alpha v1 NEAR Testnet помогает показать, что агроинвестиционные workflow можно связать с прозрачной цифровой инфраструктурой до production deployment.

## 5:30-6:45 - Investment Ask

Сейчас AgriPartners ищет стратегическую поддержку, чтобы перейти от Alpha v1 demonstration к credible pilot investment package.

Мы ищем:

- Strategic investors, которые понимают agriculture, emerging markets и infrastructure-stage opportunities.
- Pilot capital partners для structured Fidlot and Hissar validation.
- Accelerators, которые помогут с fundraising discipline, market access, legal readiness и investor packaging.
- NEAR ecosystem feedback, technical review, grant consideration и introductions.
- Regional partners для farmer/operator sourcing, verification и operational oversight.
- Legal and compliance guidance для cross-border investment structures.

Непосредственная цель - не широкий публичный запуск. Непосредственная цель - дисциплинированная pilot validation с партнерами, которые понимают agriculture, capital formation и trust infrastructure.
