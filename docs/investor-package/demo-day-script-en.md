# AgriPartners Demo Day Script

Duration: 5-7 minutes.

Flow: Investor -> Farmer -> Admin -> NEAR Testnet -> Investment Ask.

## 0:00-0:45 - Opening

Hello, I am presenting AgriPartners Alpha v1.

AgriPartners is an agricultural investment workflow platform. We help investors review pilot deal economics, monitor operational progress, track returns, and validate project activity through a clear digital interface.

Our first demo focuses on two agricultural pilot models:

- Fidlot Livestock Project, a completed livestock fattening pilot.
- Hissar Sheep Breeding Project, an active sheep breeding pilot.

Together, these pilots represent $100,000 in total pilot funding and $163,650 in expected returns.

## 0:45-2:15 - Investor Portal

I will start from the investor view because this is where capital providers need immediate clarity.

On the Investor Dashboard, the investor sees portfolio-level metrics: total invested capital, expected returns, returned amount, outstanding amount, active deals, completed deals, and ROI.

The current pilot portfolio shows:

- $100,000 total pilot funding.
- $163,650 expected returns.
- $82,000 returned.
- One active deal and one completed deal.

Next, we show Featured Pilot Deals. Fidlot is the completed livestock project with $50,000 invested, 64% ROI, 21.9% APR, and 7 cycles. Hissar is the active sheep breeding project with $50,000 invested, 63.3% projected ROI, 21.1% APR, and 6 cycles.

The important point is that an investor can compare agricultural projects in a familiar investment format before going deeper into technical details.

## 2:15-3:15 - Farmer Portal

Now we switch to the Farmer Portal.

The farmer sees a practical operating view: funding confirmation, active and completed deals, cycle progress, and reporting status.

For Fidlot, the project is completed and the report has been submitted. For Hissar, the project is active, the first cycle is underway, and the next report is due.

This view matters because investor trust depends on reporting discipline. AgriPartners is not only presenting investment cards; it is also structuring the operational behavior behind those cards.

## 3:15-4:25 - Admin Dashboard

Next is the Admin Dashboard.

The admin view gives controlled monitoring across the pilot portfolio. Admins can review project status, funding, ROI or projected ROI, APR, farmer reporting status, return status, and event history.

For the current pilots, the admin metrics show $100,000 in total pilot funding, $82,000 returned, and $81,650 outstanding. Fidlot is completed with return recorded. Hissar is active with pending returns.

This layer is important for accelerators, funds, and strategic investors because pilot-scale agricultural finance needs operational oversight before it can scale.

## 4:25-5:30 - NEAR Testnet

Now we move to the NEAR Testnet layer.

AgriPartners uses NEAR Testnet to demonstrate wallet-authenticated access, contract-aware workflows, and transparent lifecycle events.

The key point is not to make investors think about blockchain complexity. The key point is trust infrastructure. NEAR can support project workflow validation, event references, and future settlement readiness behind an investor-friendly product interface.

In the current Alpha v1, NEAR Testnet helps prove that agricultural investment workflows can be connected to transparent digital infrastructure before production deployment.

## 5:30-6:45 - Investment Ask

AgriPartners is now seeking strategic support to move from Alpha v1 demonstration into a credible pilot investment package.

We are looking for:

- Strategic investors who understand agriculture, emerging markets, and infrastructure-stage opportunities.
- Pilot capital partners for structured Fidlot and Hissar validation.
- Accelerators that can support fundraising discipline, market access, legal readiness, and investor packaging.
- NEAR ecosystem feedback, technical review, grant consideration, and introductions.
- Regional partners for farmer/operator sourcing, verification, and operational oversight.
- Legal and compliance guidance for cross-border investment structures.

The immediate goal is not a broad public launch. The immediate goal is disciplined pilot validation with partners who understand agriculture, capital formation, and trust infrastructure.

Thank you. I would be happy to walk through the investor dashboard, farmer reporting, admin controls, and NEAR Testnet workflow in more detail.
