# AgriPartners One-Pager v1

## Обзор

AgriPartners — это инвестиционная платформа для сельского хозяйства, которая показывает экономику реальных пилотных проектов, операционную отчетность и отслеживание возвратов через дашборд, готовый для инвесторов.

## Фокус Alpha v1

- Главный инвесторский дашборд.
- Карточки избранных пилотных проектов.
- Детальные страницы профилей проектов.
- Видимость фермерской отчетности.
- Сводки по возвратам и ROI.
- Демонстрационный процесс на NEAR Testnet.
