# AgriPartners Demo Video Script v2

## Audience

This script is designed for:

- NEAR Foundation.
- European investors.
- Japanese investors.
- Chinese investors.
- Regional and international investors.
- Investment funds, ecosystem partners, and accelerators.

The tone should be professional, direct, and practical. Avoid hype. Emphasize investor understanding, agricultural use cases, and workflow transparency.

## Target Length

3 to 5 minutes.

Recommended recording setup:

- Browser size: 1440 x 900 px.
- Zoom level: 100%.
- Capture format: 1080p video.
- Start with the investor dashboard already logged in.
- Keep cursor movement slow and intentional.

## Page Sequence

1. Investor Dashboard: `/#investor`
2. Featured Pilot Deals: `/#investor`
3. Fidlot Project Profile: `/#investor/deals/1`
4. Hissar Project Profile: `/#investor/deals/2`
5. Farmer Report: `/#farmer/deals/1`
6. ROI and Returns: `/#investor/deals/1`
7. Event History: `/#investor/deals/1`
8. Admin Portal: `/#admin`
9. Closing on Investor Dashboard: `/#investor`

## Recording Notes

- Keep the demo focused on investor understanding.
- Do not over-explain blockchain mechanics.
- Do not promise guaranteed returns.
- Refer to the current product as Alpha v1.
- Refer to NEAR Testnet as the demonstration layer, not final production settlement.
- Pause briefly on each financial metric so it can be read.
- Avoid showing browser tabs, credentials, private keys, database tools, terminal windows, or internal notes.
