AgriPartners - это working Alpha v1 MVP для прозрачных агроинвестиционных workflows на NEAR. Проект начинается с livestock pilots в Центральной Азии и помогает инвесторам оценивать агросделки, фермерам - отчитываться о ходе работы, а партнерам - отслеживать lifecycle events через структурированные цифровые процессы.

Текущий MVP включает:

- Investor Dashboard для portfolio metrics, pilot deals, ROI, expected returns, returned amount и outstanding amount.
- Farmer Portal для funding visibility, cycle progress, active deals, completed deals и reporting status.
- Admin Dashboard для deal monitoring, reporting oversight, repayment status и event history.
- Backend API и investor documentation package.

Сейчас AgriPartners использует NEAR Testnet для валидации wallet-authenticated access, contract-aware deal flows, lifecycle events и future settlement readiness. Mainnet launch зависит от security audit, legal readiness и partner validation.
