## Usage Scenarios

### Intro Message

Use for Telegram, Discord, X/Twitter DM, and LinkedIn. Best for first contact when the recipient does not know AgriPartners yet.

### Follow-up Message

Use after no response, after a first conversation, or after sending a deck. Keep the tone light and specific.

### Project Introduction Email

Use for formal ecosystem introductions, grant-related conversations, program applications, accelerator contacts, and partner referrals.

### Meeting Request

Use when the recipient already has basic context and the goal is to ask for a 15-30 minute conversation.

### Feedback Request

Use when the recipient is a builder, ecosystem operator, partner, mentor, or reviewer who can provide technical, ecosystem, or partnership feedback.

## Recommended First-Use Order

1. Send the intro message for first contact.
2. If there is interest, send the project introduction email with links and deck availability.
3. Use the meeting request to ask for a 15-30 minute conversation.
4. After the meeting, send the feedback request with specific questions.
5. Use the follow-up message if there is no response or after sending materials.

## Positioning Reminder

Present AgriPartners as a working Alpha v1 MVP with NEAR Testnet validation. Do not describe it as a production investment platform until audit, legal readiness, and partner validation are complete.
