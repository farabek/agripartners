## Usage Scenarios

### Intro Message

Используйте для Telegram, Discord, X/Twitter DM и LinkedIn. Лучше всего подходит для первого контакта, когда получатель еще не знает AgriPartners.

### Follow-up Message

Используйте после отсутствия ответа, после первого разговора или после отправки deck. Сохраняйте легкий и конкретный тон.

### Project Introduction Email

Используйте для формальных экосистемных интро, грантовых разговоров, program applications, контактов с акселераторами и партнерских referrals.

### Meeting Request

Используйте, когда у получателя уже есть базовый контекст, а цель - попросить о разговоре на 15-30 минут.

### Feedback Request

Используйте, когда получатель является builder, ecosystem operator, partner, mentor или reviewer, который может дать technical, ecosystem или partnership feedback.

## Recommended First-Use Order

1. Отправьте intro message для первого контакта.
2. Если есть интерес, отправьте project introduction email со ссылками и доступностью deck.
3. Используйте meeting request, чтобы попросить о разговоре на 15-30 минут.
4. После встречи отправьте feedback request с конкретными вопросами.
5. Используйте follow-up message, если ответа нет или после отправки материалов.

## Positioning Reminder

Представляйте AgriPartners как рабочий Alpha v1 MVP с NEAR Testnet validation. Не описывайте проект как production investment platform до аудита, юридической готовности и проверки с партнерами.
