My name is Farhod Muhamadiev, founder of AgriPartners.

AgriPartners is a working Alpha v1 MVP for transparent agricultural investment workflows on NEAR. The project starts with livestock pilots in Central Asia and is designed to help investors review agricultural deals, help farmers report operational progress, and help partners monitor lifecycle events through structured digital workflows.

The current MVP includes:

- Investor Dashboard for portfolio metrics, pilot deals, ROI, expected returns, returned amount, and outstanding amount.
- Farmer Portal for funding visibility, cycle progress, active deals, completed deals, and reporting status.
- Admin Dashboard for deal monitoring, reporting oversight, repayment status, and event history.
- Backend API and investor documentation package.

AgriPartners currently uses NEAR Testnet to validate wallet-authenticated access, contract-aware deal flows, lifecycle events, and future settlement readiness. Mainnet launch is pending security audit, legal readiness, and partner validation.
