# Alpha v1.2 Screenshot Pack

Captured on September 2, 2026 from the current Alpha v1.2 demo state at a 1440 × 1000 desktop viewport.

The pack follows the investor story in `docs/demo-readiness/06-demo-screenshot-guide.md`:

1. login and role entry;
2. investor portfolio dashboard;
3. active Hissar deal;
4. farmer reporting;
5. completed Fidlot deal;
6. ROI and settlement visibility;
7. admin oversight.

To refresh the pack, run `npm run capture:screenshots` from `frontend/`. Set `AGRIPARTNERS_SCREENSHOT_URL` to capture a local or preview deployment instead of production.

These screens use demonstration data. Projected returns are illustrative and are not guaranteed.
