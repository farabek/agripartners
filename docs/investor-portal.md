# Investor Portal

The Investor Portal presents the pilot portfolio in an investor-ready format. It focuses on clear project names, funding amounts, projected and realized returns, and the current status of active and completed investments.

## Investor Dashboard

The dashboard starts with wallet context and an investor profile area. This confirms that the user is authenticated and that portfolio information is loaded through wallet-protected routes.

Screenshot:

![Investor header](screenshots/investor/01-investor-header.png)

## Investor Profile

The investor profile captures basic investor information such as wallet account, display name, country, investor type, risk profile, and KYC status. In the demo, this section shows how investor metadata can be connected to wallet identity.

## ROI Tracking

The Investor Portal distinguishes between completed and active projects:

- Completed projects use ROI.
- Active projects use Projected ROI.

This keeps the financial language clear for investors reviewing the demo.

## Returns Tracking

Returns tracking shows how completed projects can record returned capital and how active projects can show outstanding expected returns. In the demo, Fidlot shows recorded returns while Hissar remains outstanding.
