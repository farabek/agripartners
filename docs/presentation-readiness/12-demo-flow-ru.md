# Demo Flow

## Purpose

Этот документ определяет 5-7 minute AgriPartners Alpha v1 demo sequence для NEAR ecosystem reviewers, investors, accelerators и strategic partners.

## Demo Timing

Target duration: 5-7 minutes.

Recommended rhythm:

| Segment | Time |
|---|---:|
| Opening context | 30 seconds |
| Login and wallet access | 45 seconds |
| Marketplace and pilot deals | 90 seconds |
| Farmer reports and deal detail | 90 seconds |
| ROI, portfolio, and funding progress | 90 seconds |
| Withdraw and NEAR use case close | 45 seconds |

## Exact Walkthrough

### 1. Login

Начните с login screen.

Show:

- `Login with NEAR Wallet`.
- NEAR Testnet wallet flow.
- Wallet-linked investor access.

Speaker point:

AgriPartners использует wallet authentication, чтобы связать investor, farmer и admin workflows с NEAR accounts.

### 2. Marketplace

Откройте Marketplace.

Show:

- Available pilot deals.
- Active and completed deal filters.
- Compact funding progress on marketplace cards.
- Deal-level investment, ROI, simple annualized ROI, cycles и status.

Speaker point:

Marketplace - место, где investors discover agricultural opportunities и compare deal profiles перед открытием detailed view.

### 3. Pilot Deal #1 - Fidlot Livestock Project

Откройте completed Fidlot livestock pilot.

Show:

- Investment amount: `$50,000`.
- ROI: `64%`.
- simple annualized ROI: `21.9%`.
- Cycles: `7`.
- Status: `Completed`.
- Funding progress: fully funded.
- Return recorded: `$82,000`.

Speaker point:

Этот profile демонстрирует completed agricultural cycle с reports, returns и event history, видимыми в investor experience.

### 4. Pilot Deal #2 - Hissar Sheep Breeding Project

Откройте active Hissar sheep breeding pilot.

Show:

- Investment amount: `$50,000`.
- Projected ROI: `63.3%`.
- simple annualized ROI: `21.1%`.
- Cycles: `6`.
- Status: `Active`.
- Funding progress: demo-safe partial funding view.
- Outstanding returns: `$81,672`.

Speaker point:

Этот profile демонстрирует active-deal state: funding visible, cycle operating, reporting/returns still in progress.

### 5. Farmer Reports

Из deal detail view покажите Farmer Reports и Cycle Status.

Show:

- Submitted report для completed pilot.
- Report due / operating status для active pilot.
- Amount used и report summary fields where available.

Speaker point:

Reporting layer связывает real farm operations с investor visibility. Investors видят не только financial number, но и execution context.

### 6. ROI Dashboard

Вернитесь к Investor Analytics Dashboard.

Show:

- ROI & Returns Overview.
- Projected Portfolio Return.
- Capital Returned.
- Outstanding Returns.
- Return Completion Rate.
- Average Projected ROI.

Speaker point:

Dashboard summarizes return progress across deals, при этом projected return language отделен от completed return language.

### 7. Portfolio Dashboard

Оставайтесь на Investor Analytics Dashboard и покажите portfolio layer.

Show:

- Portfolio Summary.
- Portfolio Performance.
- Portfolio Health.
- Recent Activity.
- Deal Performance.
- Active and Completed Investments.

Speaker point:

Это не отдельная page. Это investor portfolio management layer внутри existing analytics dashboard.

### 8. Funding Progress

Укажите funding progress на Marketplace cards и deal detail panels.

Show:

- Funding Goal.
- Amount Raised.
- Remaining Amount.
- Funding Percentage.
- Investor Count.
- Days Remaining.

Speaker point:

Funding progress помогает investors понять, находится ли deal still raising capital, already funded или ready to move into operational cycles.

### 9. Withdraw

Откройте investor action area в deal detail.

Show:

- Investor withdrawal button.
- Testnet MVP warning.
- Transaction hash visibility after withdrawal where available.

Speaker point:

Current withdrawal flow демонстрирует smart-contract interaction и wallet-linked fund movement на NEAR Testnet. Production return distribution является future phase.

## Closing Line

AgriPartners Alpha v1 демонстрирует full shape agricultural RWA platform: marketplace discovery, wallet-based access, farm reporting, funding progress, investor portfolio analytics, ROI tracking и NEAR-based verification.
