# Demo Flow

## Purpose

This document defines the 5-7 minute AgriPartners Alpha v1 demo sequence for NEAR ecosystem reviewers, investors, accelerators, and strategic partners.

## Demo Timing

Target duration: 5-7 minutes.

Recommended rhythm:

| Segment | Time |
|---|---:|
| Opening context | 30 seconds |
| Login and wallet access | 45 seconds |
| Marketplace and pilot deals | 90 seconds |
| Farmer reports and deal detail | 90 seconds |
| ROI, portfolio, and funding progress | 90 seconds |
| Withdraw and NEAR use case close | 45 seconds |

## Exact Walkthrough

### 1. Login

Start on the login screen.

Show:

- `Login with NEAR Wallet`.
- NEAR testnet wallet flow.
- Wallet-linked investor access.

Speaker point:

AgriPartners uses wallet authentication to connect investor, farmer, and admin workflows to NEAR accounts.

### 2. Marketplace

Open Marketplace.

Show:

- Available pilot deals.
- Active and completed deal filters.
- Compact funding progress on marketplace cards.
- Deal-level investment, ROI, APR, cycles, and status.

Speaker point:

Marketplace is where investors discover agricultural opportunities and compare deal profiles before opening a detailed view.

### 3. Pilot Deal #1 - Feedlot Livestock Project

Open the completed Feedlot / Fidlot livestock pilot.

Show:

- Investment amount: `$50,000`.
- ROI: `64%`.
- APR: `21.9%`.
- Cycles: `7`.
- Status: `Completed`.
- Funding progress: fully funded.
- Return recorded: `$82,000`.

Speaker point:

This profile demonstrates a completed agricultural cycle with reports, returns, and event history visible in the investor experience.

### 4. Pilot Deal #2 - Hissar Sheep Breeding Project

Open the active Hissar sheep breeding pilot.

Show:

- Investment amount: `$50,000`.
- Projected ROI: `63.3%`.
- APR: `21.1%`.
- Cycles: `6`.
- Status: `Active`.
- Funding progress: demo-safe partial funding view.
- Outstanding returns: `$81,672`.

Speaker point:

This profile demonstrates the active-deal state: funding is visible, the cycle is operating, and reporting/returns are still in progress.

### 5. Farmer Reports

From the deal detail view, show Farmer Reports and Cycle Status.

Show:

- Submitted report for the completed pilot.
- Report due / operating status for the active pilot.
- Amount used and report summary fields where available.

Speaker point:

The reporting layer connects real farm operations to investor visibility. Investors do not only see a financial number; they see execution context.

### 6. ROI Dashboard

Return to the Investor Analytics Dashboard.

Show:

- ROI & Returns Overview.
- Projected Portfolio Return.
- Capital Returned.
- Outstanding Returns.
- Return Completion Rate.
- Average Projected ROI.

Speaker point:

The dashboard summarizes return progress across deals while keeping projected return language separate from completed return language.

### 7. Portfolio Dashboard

Stay on the Investor Analytics Dashboard and show the portfolio layer.

Show:

- Portfolio Summary.
- Portfolio Performance.
- Portfolio Health.
- Recent Activity.
- Deal Performance.
- Active and Completed Investments.

Speaker point:

This is not a separate page. It is the investor's portfolio management layer inside the existing analytics dashboard.

### 8. Funding Progress

Point to funding progress on Marketplace cards and deal detail panels.

Show:

- Funding Goal.
- Amount Raised.
- Remaining Amount.
- Funding Percentage.
- Investor Count.
- Days Remaining.

Speaker point:

Funding progress helps investors understand whether a deal is still raising capital, already funded, or ready to move into operational cycles.

### 9. Withdraw

Open the investor action area in deal detail.

Show:

- Investor withdrawal button.
- Testnet MVP warning.
- Transaction hash visibility after withdrawal where available.

Speaker point:

The current withdrawal flow demonstrates smart-contract interaction and wallet-linked fund movement on NEAR testnet. Production return distribution is a future phase.

## Closing Line

AgriPartners Alpha v1 demonstrates the full shape of an agricultural RWA platform: marketplace discovery, wallet-based access, farm reporting, funding progress, investor portfolio analytics, ROI tracking, and NEAR-based verification.
