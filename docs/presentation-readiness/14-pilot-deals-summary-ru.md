# Pilot Deals Summary

## Overview

AgriPartners Alpha v1 использует два agricultural pilot profiles для демонстрации active и completed deal states.

## Fidlot Livestock Project

| Field | Value |
|---|---:|
| Investment Amount | `$50,000` |
| Cycles | `7` |
| ROI | `64%` |
| simple annualized ROI | `21.9%` |
| Status | Completed |

Summary:

Fidlot Livestock Project представляет completed livestock fattening pilot profile. Он используется, чтобы показать finished agricultural cycle, completed reporting, returned capital, ROI visibility и investor-facing deal history.

Demo signals:

- Completed deal status.
- `$82,000` returned amount.
- `$0` outstanding amount.
- Farmer report submitted.
- Return recorded.
- Event history available.

## Presentation Use

Используйте два pilots вместе:

- Fidlot показывает completed-state story.
- Hissar показывает active-state story.

Вместе они демонстрируют, как AgriPartners handles marketplace discovery, funding visibility, farmer reporting, ROI tracking, portfolio health и deal lifecycle transparency.
