# Pilot Deals Summary

## Overview

AgriPartners Alpha v1 uses two agricultural pilot profiles to demonstrate active and completed deal states.

## Feedlot Livestock Project

| Field | Value |
|---|---:|
| Investment Amount | `$50,000` |
| Cycles | `7` |
| ROI | `64%` |
| APR | `21.9%` |
| Status | Completed |

Summary:

The Feedlot Livestock Project represents a completed livestock fattening pilot profile. It is used to show a finished agricultural cycle, completed reporting, returned capital, ROI visibility, and investor-facing deal history.

Demo signals:

- Completed deal status.
- `$82,000` returned amount.
- `$0` outstanding amount.
- Farmer report submitted.
- Return recorded.
- Event history available.

## Hissar Sheep Breeding Project

| Field | Value |
|---|---:|
| Investment Amount | `$50,000` |
| Cycles | `6` |
| ROI | `63.3%` |
| APR | `21.1%` |
| Status | Active |

Summary:

The Hissar Sheep Breeding Project represents an active livestock breeding pilot profile. It is used to show an operating agricultural cycle, funding progress, outstanding projected returns, and reporting visibility before completion.

Demo signals:

- Active deal status.
- Cycle active / current cycle visible.
- `$81,650` projected return.
- `$81,650` outstanding amount.
- Farmer report visibility.
- Funding progress available.

## Presentation Use

Use the two pilots together:

- Feedlot shows the completed-state story.
- Hissar shows the active-state story.

Together they demonstrate how AgriPartners handles marketplace discovery, funding visibility, farmer reporting, ROI tracking, portfolio health, and deal lifecycle transparency.
