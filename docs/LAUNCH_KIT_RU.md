# AgriPartners Alpha v1 Launch Kit

AgriPartners Alpha v1 Launch Kit - основной навигационный документ для всех launch-материалов текущего демонстрационного пакета Alpha v1.

Этот документ предназначен для NEAR Foundation, NEAR Horizon, акселераторов, стратегических партнеров и инвесторов, которые рассматривают проект. Он собирает в одном месте ссылки на product, demo, presentation, NEAR, validation и GitHub материалы.

AgriPartners Alpha v1 - validation-stage demonstration platform на NEAR Testnet. Документ не заявляет production deployment, audited smart contracts или live mainnet operations.

## 1. Project Overview

- [Executive Summary](presentation-readiness/01-executive-summary.md) - краткое описание проблемы, решения, агро-фокуса, blockchain fit и текущего позиционирования Alpha v1.
- [Core Narrative](demo-readiness/15-core-narrative-ru.md) - основной narrative для объяснения, зачем существует AgriPartners и как презентовать demo.
- [Platform Metrics](presentation-readiness/03-platform-metrics.md) - текущие demo portfolio metrics, основанные только на Alpha v1 data: active deals, completed deals, listed capital, returned capital, ROI и simple annualized ROI.

Эти документы лучше всего подходят для первого понимания того, что такое AgriPartners, почему проект существует и что демонстрирует текущий Alpha v1 package.

## 6. NEAR

- [NEAR Use Case](near-outreach/15-near-use-case-ru.md) - объясняет, как Alpha v1 использует NEAR для wallet authentication, smart contract interaction, withdrawal demo flows и verification.
- [Current Testnet Status](near-testnet-ru.md) - описывает текущий NEAR Testnet positioning, wallet accounts, smart contract usage, transaction flow и pilot lifecycle.

Current implementation: AgriPartners Alpha v1 использует NEAR Testnet для wallet-linked access, contract-aware demo flows, transaction-oriented lifecycle actions и blockchain-verifiable demo signals.

Future roadmap: Mainnet readiness, tokenization, expanded on-chain settlement и institutional-grade workflows требуют дополнительной beta validation, legal review, compliance review, smart contract audit planning и production readiness work.

## 7. Validation

- [Wave 1 Tracking](near-execution/18-wave1-tracking-ru.md) - отслеживает outreach и validation activity.
- [Validation Log](near-execution/19-validation-log-ru.md) - фиксирует validation progress и reviewer feedback.
- [Target List](near-execution/20-wave1-target-list-ru.md) - содержит initial outreach targets.

- [Outreach Messages](near-execution/23-outreach-messages-ru.md) - содержит message templates для reviewer, partner и ecosystem outreach.

Validation workflow:

1. Определить relevant targets.
2. Приоритизировать NEAR ecosystem, accelerator, strategic partner и investor contacts.
3. Отправить structured outreach messages.
4. Отслеживать responses и next steps.
5. Фиксировать feedback в validation record.
6. Использовать feedback для уточнения pitch, demo, pilot readiness и partnership path.
