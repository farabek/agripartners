# Farmer Portal

The Farmer Portal gives the operating farm a clean view of assigned pilot deals, funding status, cycle progress, and reporting responsibilities.

## Farmer Profile

The demo profile represents the operating farm as:

- Display name: AgriPartners Pilot Farm.
- Role: farmer.
- Operator description: Livestock pilot operator.

This profile helps investor screenshots show the farmer as a real operating counterparty rather than a test wallet.

Screenshot:

![Farmer profile](screenshots/farmer/01-farmer-profile.png)

## Farmer Metrics

The farmer metrics summarize the pilot workload:

- Active deals.
- Completed deals.
- Total funding.
- Active cycles.
- Pending reports.

The demo view presents funding in USD for clarity.

Screenshot:

![Farmer metrics](screenshots/farmer/02-farmer-metrics.png)

## Funding Status

Each farmer deal card shows whether funding has been confirmed. For both pilot projects, the demo shows Funding Confirmed, which communicates that the farmer can proceed with operations.

## Cycle Tracking

Cycle tracking shows where each project stands:

- Fidlot Livestock Project is completed.
- Hissar Sheep Breeding Project is active with cycle 1 underway.

## Reports

The portal uses farmer-friendly reporting labels:

- Report Submitted for the completed Fidlot pilot.
- Next Report Due for the active Hissar pilot.

Screenshot:

![Fidlot farmer card](screenshots/farmer/03-fidlot-card.png)

## Active Deals

The farmer deals list shows the clean pilot projects assigned to the farm. Cards include project name, status, investor, funding amount, funding status, and report status.
