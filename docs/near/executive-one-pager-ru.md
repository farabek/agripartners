## 1. Обзор проекта

AgriPartners - Alpha-stage платформа для прозрачных сельскохозяйственных инвестиционных workflows. Она соединяет инвесторов, фермеров и операторов платформы через marketplace, role-based порталы, farmer reporting, returns tracking и Treasury Shadow Mode. Текущий продукт использует NEAR Testnet для wallet-linked workflows и smart contract experimentation, сохраняя осторожную финансовую терминологию. AgriPartners пока не является production investment, custody, payout или Mainnet settlement system. Alpha-продукт показывает, как сельскохозяйственный капитал можно представить, мониторить, сопровождать отчетностью и готовить к более сильной reconciliation и Treasury controls.

## 2. Проблема

Сельскохозяйственное финансирование сложно отслеживать после того, как капитал выходит из поля зрения инвестора. Инвесторы часто получают ограниченную операционную прозрачность, farmer updates фрагментированы, а отчетность может жить в сообщениях, таблицах и ручных записях. Из-за этого доверие между инвесторами, операторами и администраторами платформы сложно установить и еще сложнее масштабировать.

Главная проблема - прозрачность workflow. Инвесторам нужно понимать, что они финансируют, на каком этапе находится проект, какие отчеты уже получены, какие returns записаны и что еще остается pending. Фермерам нужен простой способ показывать операционный прогресс. Команде платформы нужен контролируемый record по deals, reports, returns и Treasury activity.

## 3. Решение

AgriPartners объединяет эти элементы в один структурированный workflow:

- Marketplace для просмотра pilot opportunities.
- Investor Portal для investment summaries, progress по pilot models, return visibility и withdrawal-readiness context.
- Farmer Portal для funding status, production cycle visibility и reporting.
- Admin Portal для deal operations, return recording, status lifecycle и oversight.
- Farmer reporting, который связывает капитал с реальной производственной активностью.
- Returns tracking с осторожной терминологией: projected, recorded, paid, reconciled.
- Treasury Shadow Mode для accounting trail без production payout enforcement на Alpha-стадии.
- Presentation Mode для понятной демонстрации продукта инвесторам, NEAR ecosystem, акселераторам и enterprise partners.

Вместе эти компоненты создают прозрачный investment workflow: от opportunity до reporting, return recording, Treasury visibility и будущей reconciliation.

## 6. Почему NEAR

NEAR хорошо подходит AgriPartners как ecosystem, потому что поддерживает user-friendly blockchain workflows без необходимости начинать продуктовый рассказ с технической сложности.

Релевантность NEAR:

- Wallet-linked access for approved Investor and Estonia-side roles, without making Farmer access
  dependent on a crypto wallet.
- Developer-friendly environment для smart contract и workflow experimentation.
- Testnet validation перед production или Mainnet decisions.
- Scalable architecture для большого количества operational events, reports, references и будущих settlement workflows.
- Transparent workflow support через transaction references, wallet identity и будущие reconciliation patterns.

AgriPartners пока не заявляет Mainnet readiness. Mainnet evaluation должен идти после усиления security, custody, reconciliation, Treasury enforcement, monitoring и compliance preparation.
