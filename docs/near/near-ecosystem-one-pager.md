# AgriPartners NEAR Ecosystem One Pager

Status: Phase 23 NEAR ecosystem summary.

Audience: NEAR Foundation, NEAR Horizon, DevRel, ecosystem teams, builders, accelerator reviewers, and technical partners.

## 1. Executive Summary

AgriPartners is an Alpha-stage agricultural investment workflow platform built around transparency, reporting, return visibility, and Treasury discipline. The product uses NEAR Testnet for wallet-linked workflows and smart contract experimentation while keeping production claims conservative. AgriPartners is relevant to the NEAR ecosystem because it demonstrates a practical real-world workflow: investors review agricultural pilot models, farmers report operating progress, administrators manage return status, and Treasury Shadow Accounting prepares the path toward stronger auditability. The project is not presenting itself as Mainnet-ready or as a production investment system. It is a working Alpha that can help NEAR ecosystem members evaluate how blockchain infrastructure can support agriculture, RWA-style workflows, and user-friendly capital transparency.

## 2. Why This Matters to NEAR

Agricultural finance is a meaningful blockchain use case because the trust problem is operational, not only financial. Capital is deployed into real-world production cycles, but investors often have limited visibility into what happened after funding. Farmers need a structured way to report progress. Platform operators need a reliable record of deals, reports, return activity, and Treasury state.

For NEAR, this matters because it shows how blockchain infrastructure can support a real-world workflow without making the user experience feel crypto-first. The value is not hype around tokenization. The value is clearer accountability: wallet-linked access, transparent workflow states, transaction references where useful, and a future path toward reconciliation between business records and execution evidence.

AgriPartners gives NEAR a concrete agriculture example where transparency, usability, and operational workflow design matter as much as smart contracts.

## 3. What Has Already Been Built

AgriPartners Alpha v1.2 includes:

- Investor Portal for portfolio visibility, pilot review, recorded return context, and withdrawal-readiness framing.
- Farmer Portal for funding status, production cycle visibility, and farmer reports.
- Admin Portal for deal oversight, return recording, status lifecycle, and operational controls.
- Marketplace for flagship pilot model review.
- Presentation Mode with audience profiles for Investor, NEAR Foundation, Accelerator, and Enterprise Partner demos.
- Treasury Shadow Accounting for non-authoritative accounting visibility.
- Treasury Dashboard for administrative review of Treasury accounts and ledger activity.
- Typed Returns and Return Status Lifecycle for more precise return classification and status tracking.
- NEAR Testnet integration for wallet-linked and smart contract workflow validation.
- Automated tests cover the Alpha workflows; current validation evidence is maintained in current
  release and repository verification records rather than as a fixed count here.

These capabilities make the project suitable for ecosystem feedback and technical review now, while still clearly remaining Alpha/Testnet.

## 4. Technical Alignment

AgriPartners aligns with NEAR principles in several practical ways:

- Approved wallet-linked UX: Investor and Estonia-side roles can use wallet identity without
  forcing non-technical users to inspect raw blockchain details; Farmer access is not dependent on
  a crypto wallet.
- Practical blockchain adoption: the product applies blockchain infrastructure to a real-world agriculture workflow rather than a speculative-only use case.
- Developer-friendly architecture: current Testnet work lets the team validate contract interactions, wallet behavior, transaction references, and future reconciliation needs before production decisions.
- Transparent workflows: investors, farmers, and operators can follow the investment story from opportunity to reports, recorded returns, Treasury visibility, and withdrawal-readiness context.
- Scalable future evolution: the workflow can later support stronger reconciliation, Treasury enforcement, partner reporting, and Mainnet evaluation if the required controls are accepted.

AgriPartners does not claim Mainnet readiness. Mainnet evaluation should follow additional security, custody, signer policy, monitoring, reconciliation, Treasury enforcement, and compliance work.

## 5. Ecosystem Contribution

AgriPartners can contribute to the NEAR ecosystem by providing:

- a real-world agriculture use case with visible business context;
- a reusable investment workflow architecture for RWA-style capital flows;
- a transparent reporting model connecting real-world operations with platform records;
- Treasury and audit discipline through Shadow Mode, typed returns, and reconciliation planning;
- a presentation-ready Alpha demo for NEAR ecosystem, accelerator, partner, and investor conversations;
- practical feedback on what non-crypto-native users need from wallet, Testnet, and future Mainnet workflows.

The project can help NEAR tell a grounded story about blockchain adoption: not just transactions, but understandable workflows for real-world operators.

Roadmap direction:

```text
Alpha
  -> Beta

Mainnet evaluation should happen only after the required security, accounting, compliance, monitoring, and Treasury enforcement questions are resolved.
