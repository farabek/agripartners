# Product

AgriPartners Alpha v1 currently demonstrates the core product workflow.

- Wallet Login: wallet-linked access and role-specific entry into the platform.
- Marketplace: agricultural pilot deal discovery and deal detail review.
- Investor Portal: portfolio metrics, active and completed deals, ROI, returns and event history.
- Farmer Portal: farmer profile, assigned deals, cycle status and reporting visibility.
- Admin Dashboard: pilot portfolio monitoring, report status, repayment status and event history.
- Funding Progress: visibility into listed capital, active funding state and lifecycle progress.
- ROI & Returns: projected and returned capital views for investor-facing review.
- Reporting: report submitted, next report due, return recorded and pending return states.
- Pilot Deals: Fidlot Livestock Project and Hissar Sheep Breeding Project demonstration profiles based on real pilot agreements.

Alpha v1 is a demo and validation-stage implementation. It does not represent production deployment.
