## Status Boundaries

Этот deck описывает AgriPartners Alpha v1 как working demo и validation-stage product.

Он не заявляет:

- Production deployment.
- Audited smart contracts.
- Live mainnet investment operations.
- Completed features beyond the current Alpha v1 demo scope.

Current product claims должны оставаться привязанными к verified Alpha v1 modules, demo portfolio data, NEAR Testnet workflows и existing pilot profiles.
