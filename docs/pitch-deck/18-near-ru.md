# Why NEAR

NEAR provides a practical infrastructure layer for transparent agricultural investment workflows.

- Wallet auth: wallet-linked identity and role-specific portal access.
- On-chain events: contract-linked activity, visible deal events, transaction hashes where available and NEAR Testnet verification.
- Low fees: suitable for repeated lifecycle actions such as funding, reporting, return recording and withdrawal-related events.
- Developer ecosystem: a strong environment for building real-world asset workflows and validating product direction.
- Future tokenization: a path toward funding pools, return distribution, cycle events and agricultural RWA infrastructure after audit, legal review and mainnet readiness work.

Current Alpha v1 uses NEAR Testnet for wallet authentication, smart contract interaction, withdrawal demo flows and blockchain-verifiable demo actions.
