## Status Boundaries

This deck describes AgriPartners Alpha v1 as a working demo and validation-stage product.

It does not claim:

- Production deployment.
- Audited smart contracts.
- Live mainnet investment operations.
- Completed features beyond the current Alpha v1 demo scope.

Current product claims should remain tied to the verified Alpha v1 modules, demo portfolio data, NEAR Testnet workflows, and existing pilot profiles.
