# AgriPartners Alpha v1.2 Release Notes

Release scope: Alpha v1.2 repository and public outreach readiness.

Status: Alpha/Testnet demonstration release. Not production investment, custody, payout, settlement, or Mainnet infrastructure.

Farmer wallet authentication, Farmer withdrawal, NEAR funding, and smart-contract payout behavior
in this release is **Legacy Testnet Alpha — historical technical demonstration, not the target
production financial architecture**. The target keeps cryptocurrency at AgriPartners OÜ in
Estonia and gives the Uzbekistan Feedlot Operator and Farmer role a fiat-only, non-crypto workflow.

## Overview

AgriPartners Alpha v1.2 is a working Alpha platform for transparent agricultural investment workflows on NEAR Testnet. The release strengthens the public product presentation, role-based demo experience, Treasury visibility, and external-review documentation needed before NEAR ecosystem outreach.

Alpha v1.2 is the current product and presentation release. It builds on the official completed
[Alpha v1.1 milestone](ALPHA_V1_1_RELEASE.md), which remains a historical release record rather
than the current presentation version.

The product remains intentionally conservative: pilot deal records, return records, Treasury Shadow Accounting, and NEAR Testnet references support workflow validation, but they are not production financial proof or audited settlement evidence.

## Major Features

- Public landing and marketplace entry points for guided review.
- Investor, farmer, and admin portals for role-specific workflows.
- Wallet authentication and NEAR Testnet integration.
- Treasury Dashboard and Treasury Shadow Accounting visibility.
- Presentation Mode for stakeholder-specific demos.
- Documentation package for NEAR ecosystem reviewers, investors, and technical reviewers.

## Investor Portal

- Investors can review pilot opportunities, portfolio context, projected economics, recorded returns, and withdrawal-readiness framing.
- Deal views separate projected, recorded, paid, and reconciled terminology to avoid overstating Alpha-stage financial certainty.
- Investor-facing materials now better support strategic investor review and controlled demo conversations.

## Farmer Portal

- Farmers can review funding status, production cycle context, reporting tasks, and assigned project progress.
- Farmer reporting remains a core trust-building workflow for connecting agricultural operations to investor-readable updates.
- The farmer experience is suitable for guided Alpha demos and controlled pilot discussions, not self-serve production onboarding.

## Admin Portal

- Admin workflows support deal oversight, reporting visibility, return records, lifecycle context, and operational monitoring.
- Admin views provide the strongest current operating picture for guided demos and internal review.
- Beta should continue improving queues, filters, evidence capture, audit trails, and exception handling.

## Treasury Dashboard

- Alpha v1.2 includes Treasury Dashboard visibility and Treasury Shadow Accounting.
- Treasury data is presented as an Alpha transparency and discipline layer.
- Treasury is not yet authoritative for production balances, custody, settlement, payouts, reconciliation, or accounting enforcement.

## Presentation Mode

- Presentation Mode is the recommended first entry point for external review.
- Audience-specific profiles support investor, NEAR ecosystem, accelerator, and enterprise partner demos.
- The demo can be explored without backend setup, database access, wallet setup, or testnet funds.

## Documentation Improvements

- Public README refreshed for Alpha v1.2 positioning.
- NEAR materials added or refined for ecosystem outreach.
- Investor one-pagers added for strategic review.
- Developer review, deployment planning, and open-source readiness notes document current limitations and next steps.
- Documentation now emphasizes Alpha/Testnet boundaries and avoids production-readiness claims.

## Test Status

- Automated backend tests are present in the repository.
- Frontend build scripts are present in the repository.
- Alpha v1.2 outreach materials reference the latest known automated test coverage as 462 passing tests across 29 suites.
- CI should run backend tests and frontend build before future public release candidates are treated as stable.

## Known Alpha Limitations

- NEAR Mainnet launch has not started.
- The platform is not a production investment offering.
- Smart contracts are unaudited.
- Treasury Shadow Accounting is non-authoritative.
- Return records are Alpha workflow records, not audited production settlement.
- Production custody, payout, KYC, AML, investor suitability, monitoring, and incident response are not implemented.
- Reconciliation validation and contract provenance need stronger public evidence before Beta or Mainnet claims.
- External contributors need clearer onboarding, security, license, and contribution policies.

## Next Milestone: Beta

The next milestone is Beta preparation focused on reviewability, trust, and controlled pilot readiness:

- Add stronger CI and reproducible validation evidence.
- Improve demo/live boundaries and role onboarding.
- Expand Treasury and reconciliation visibility.
- Add clearer evidence, status history, and operational review flows.
- Prepare security, compliance, custody, and monitoring plans before any production or Mainnet evaluation.
