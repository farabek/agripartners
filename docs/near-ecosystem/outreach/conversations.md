# Ecosystem Conversations

## Purpose

Use this file to preserve reusable ecosystem learning from meaningful conversations without
creating a second relationship log. The
[canonical Relationship CRM](../../outreach/outreach-crm.md) remains authoritative for every
person, interaction, relationship status, and dated next action.

Do not copy an entire CRM record here. Add a knowledge note only when feedback should inform
multiple project profiles or integration decisions, and link back to the relevant CRM contact.
