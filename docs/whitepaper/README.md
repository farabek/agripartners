## Format Rules

- DOCX is the editable review format.
- PDF is the distribution format.
- PDF files should not be edited directly.
- Future Markdown source files may be added as the canonical source of truth when the document is converted into Markdown.

## Usage

Use these documents for:

- NEAR ecosystem conversations;
- investor and partner outreach;
- strategic introductions;
- platform explanation;
- early-stage feedback conversations.

## Important Positioning

AgriPartners is currently an Alpha platform on NEAR Testnet.

It should not be described as:

- a production investment platform;
- a custody provider;
- a live payout or settlement system;
- a Mainnet financial system;
- a regulated investment product.

The documents should be used for explanation, feedback, review, and strategic conversations.
