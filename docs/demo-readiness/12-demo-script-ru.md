# Демо-скрипт

## Цель

Этот script поддерживает три длины демо для investors, accelerators и NEAR ecosystem partners.

## 3-Minute Version

### Opening

AgriPartners is an agricultural investment platform, которая помогает инвесторам review pilot deals, track farmer updates и monitor projected returns.

### Flow

1. Начать с Investor Login.
2. Открыть Investor Dashboard.
3. Подсветить два pilot profiles: Hissar Sheep как active и Fidlot как completed.
4. Открыть Hissar Sheep и показать active deal, farmer report и returns view.
5. Открыть Fidlot и показать completed status, returned amount, outstanding return и ROI summary.
6. Кратко открыть Admin Dashboard и показать operational oversight.

### Audience Emphasis

Investors:

- Clear deal-level return visibility.
- Completed pilot evidence.
- Simple summary of projected and returned capital.

Accelerators:

- MVP is demoable and structured.
- Pilot data is clean and repeatable.
- Roadmap может расширяться к partnerships и program applications.

NEAR ecosystem partners:

- NEAR wallet and ecosystem alignment.
- Clear future path для deeper on-chain workflows.
- Practical real-world asset use case.

### Close

Alpha v1 demo показывает, что AgriPartners может ясно и прозрачно presenting agricultural investment activity и готов к ecosystem feedback.

## 5-Minute Version

### Opening

AgriPartners Alpha v1 отвечает на один главный вопрос: можно ли показать agricultural pilot deals инвесторам достаточно ясно для feedback, validation и partnership conversations?

### Flow

1. Investor Login: показать вход в investor experience.
2. Investor Dashboard: объяснить active и completed pilot structure.
3. Active Deal (Hissar Sheep): показать funding, projected ROI, farmer report и current return state.
4. Farmer Report: объяснить operational reporting и investor transparency.
5. Returns View: показать visibility по returns и то, что projected returns are estimates.
6. Completed Deal (Fidlot): показать returned amount, outstanding return, completed status и ROI summary.
7. Admin Dashboard: показать return summary, returns ledger и record return workflow.

### Audience Emphasis

Investors:

- Focus on risk visibility, return status и deal-level reporting.

Accelerators:

- Focus on MVP completeness, repeatable demo flow и user clarity.

NEAR ecosystem partners:

- Focus on wallet readiness, ecosystem relevance и future smart contract expansion.

### Close

MVP intentionally narrow: он показывает investor reporting, farmer updates, return visibility и admin oversight без overpromising automated financial execution.

## 10-Minute Version

### Opening

AgriPartners строит bridge между agricultural operators и investors. Alpha v1 демонстрирует reporting и operational layer, которые нужны перед scaling to deeper automation.

### Flow

1. Investor Login: объяснить investor-first demo framing.
2. Investor Dashboard: пройти portfolio metrics, active deals, completed deals, projected returns, returned amount и outstanding amount.
3. Active Deal (Hissar Sheep): объяснить, зачем нужен active pilot и как investors review in-progress operations.
4. Farmer Report: прочитать report и связать его с real-world agricultural transparency.
5. Returns View: объяснить no-return или partial-return states и non-guaranteed projection disclaimer.
6. Completed Deal (Fidlot): показать completed pilot и объяснить, почему это proof point.
7. ROI Summary: показать projected ROI, projected return, returned amount, outstanding return и completed return status.
8. Admin Dashboard: показать return summary, returns ledger, farmer cycle status и existing record return workflow.
9. Positioning: объяснить, как демо поддерживает investor validation, accelerator applications и NEAR ecosystem conversations.

### Audience Emphasis

Investors:

- Deal-level summaries reduce ambiguity.
- Reports помогают evaluate operations.
- Completed Fidlot data demonstrates intended end state.

Accelerators:

- MVP has a clear user journey.
- Demo data is controlled and presentation-ready.
- Next steps can focus on validation, onboarding и partnerships.

NEAR ecosystem partners:

- Product has a practical real-world asset narrative.
- Wallet login и future contract integration align with ecosystem priorities.
- MVP can become a stronger showcase with more on-chain events and verified partner workflows.

### Close

AgriPartners Alpha v1 готов для structured feedback. Следующая цель - использовать demo для validation investor understanding, partner interest и ecosystem fit.
