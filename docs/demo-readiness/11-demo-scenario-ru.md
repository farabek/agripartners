# Демо-сценарий

## Цель

Этот сценарий готовит AgriPartners Alpha v1 для демонстраций инвесторам, партнерам, акселераторам и NEAR ecosystem teams.

## Walkthrough Flow

Investor Login -> Investor Dashboard -> Active Deal (Hissar Sheep) -> Farmer Report -> Returns View -> Completed Deal (Fidlot) -> ROI Summary -> Admin Dashboard

## Screen Sequence

### 1. Investor Login

Estimated timing: 20-30 секунд

Talking points:

- AgriPartners поддерживает отдельный investor experience.
- Демо начинается с точки зрения инвестора, потому что investor clarity является главным MVP objective.
- Wallet и account-based access можно позиционировать как часть NEAR ecosystem readiness.

### 2. Investor Dashboard

Estimated timing: 30-45 секунд

Talking points:

- Dashboard summarizes active and completed pilot deals.
- Инвестор видит capital allocation, projected returns, returned amount, outstanding amount и deal status.
- Dashboard предназначен для быстрого обзора перед открытием deal-level details.

### 3. Active Deal: Hissar Sheep Pilot

Estimated timing: 45-60 секунд

Talking points:

- Hissar Sheep является active pilot profile.
- Deal еще в процессе, поэтому return status не должен показывать completed return.
- Этот экран показывает, как инвестор отслеживает active agricultural project.

### 4. Farmer Report

Estimated timing: 45-60 секунд

Talking points:

- Farmer reports дают инвестору operational context beyond financial numbers.
- Reports связывают on-chain deal tracking с real-world agricultural progress.
- Это полезно для investors, accelerators и ecosystem partners, которые оценивают transparency.

### 5. Returns View

Estimated timing: 30-45 секунд

Talking points:

- Returns view показывает, были ли recorded repayments.
- MVP разделяет return ledger visibility и smart contract transfer execution.
- Projected returns are estimates and are not guaranteed.

### 6. Completed Deal: Fidlot Pilot

Estimated timing: 45-60 секунд

Talking points:

- Fidlot является completed pilot profile.
- Он показывает completed flow от funding до recorded return.
- Completed deal является самым сильным proof point для демо.

### 7. ROI Summary

Estimated timing: 45-60 секунд

Talking points:

- ROI считается на deal level с использованием projected ROI.
- Summary показывает projected return, returned amount, outstanding return и return status.
- Completed deals должны показывать Return Status as Completed, если returned amount равен или превышает projected return.

### 8. Admin Dashboard

Estimated timing: 60-90 секунд

Talking points:

- Admin users могут проверять deal operations, farmer cycle status, return summary и returns ledger.
- Record Return остается ledger action в MVP.
- Admin view демонстрирует operational readiness для managed pilot program.

## Recommended Timing

Short walkthrough: 3 минуты

Standard walkthrough: 5 минут

Full walkthrough with discussion: 10 минут

## Demo Close

Завершить тремя тезисами:

- AgriPartners связывает agricultural pilot funding с transparent investor reporting.
- NEAR дает credible technical foundation для wallet access и будущих on-chain workflows.
- Alpha v1 demo готово для feedback от investors, accelerators, partners и ecosystem teams.
