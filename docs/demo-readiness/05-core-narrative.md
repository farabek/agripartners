# Core Narrative

## Purpose

This document defines the core AgriPartners Alpha v1 narrative for NEAR ecosystem conversations, accelerator discussions, ecosystem partner review, and investor introductions.

The narrative should stay aligned with Central Asia agriculture, farmer financing, transparency, reporting, ROI tracking, and NEAR infrastructure.

## One-Sentence Version

AgriPartners is an Alpha v1 platform for transparent agricultural financing in Central Asia, helping investors track farmer projects, reports, ROI, and deal lifecycle activity through NEAR-enabled infrastructure.

## 30-Second Version

AgriPartners helps turn farmer financing in Central Asia into a more transparent digital workflow.

The Alpha v1 MVP lets investors review agricultural pilot deals, track active and completed projects, follow farmer reporting, and monitor ROI, returned amounts, and outstanding returns. NEAR infrastructure supports the project as a practical foundation for wallet-based access, lifecycle tracking, and future on-chain transparency.

The goal is not to present a production investment platform yet. The goal is to show a working demo that is ready for ecosystem feedback, accelerator review, partner validation, and investor-readiness conversations.

## 60-Second Version

AgriPartners is building a transparency layer for agricultural financing in Central Asia, starting with livestock pilot projects.

Many farmers and agricultural operators need working capital before revenue is generated, while investors need clearer visibility into project status, reporting discipline, ROI, returned amounts, and outstanding returns. Today, these workflows are often managed through offline communication, fragmented records, and informal reporting.

AgriPartners Alpha v1 shows how this can become a structured digital process. Investors can review active and completed pilot deals, see farmer updates, monitor return status, and understand deal-level performance. Farmers can report operational progress, and admins can oversee deal status, reporting, and return records.

NEAR provides the infrastructure direction for wallet access, transaction-aware workflows, and future smart contract lifecycle tracking. The current MVP is positioned for feedback, technical review, accelerator preparation, ecosystem partnerships, and investor-readiness validation.

## 3-Minute Version

AgriPartners is focused on a practical problem in Central Asia agriculture: farmers and agricultural operators often need financing before production generates revenue, while investors need reliable visibility into how projects are progressing.

In livestock and other agricultural cycles, the core questions are simple but important. Has the project been funded? Is the production cycle active? Has the farmer reported progress? What return is expected? What amount has been returned? What is still outstanding? Without a structured system, these questions are often answered through manual communication, spreadsheets, paper agreements, and fragmented updates.

AgriPartners Alpha v1 turns that workflow into a demo-ready product experience. The investor dashboard shows active and completed pilot deals, portfolio-level metrics, projected ROI, returned amounts, and outstanding returns. Deal views show the difference between an active project, such as the Hissar pilot, and a completed project, such as the Fidlot pilot. Farmer reporting connects operational progress to investor visibility, while the admin dashboard gives a controlled view of deal operations, return records, and reporting status.

This is where NEAR infrastructure matters. AgriPartners is not using blockchain as a slogan. The project uses NEAR as the direction for wallet-based access, contract-aware lifecycle events, transparent state tracking, and future on-chain accountability. The Alpha v1 demo shows the business workflow first, then explains how NEAR can strengthen trust, auditability, and ecosystem-level validation over time.

For the NEAR ecosystem, AgriPartners is a practical RWA and emerging-market use case. For accelerators, it is a focused Alpha v1 MVP with a clear user journey, pilot structure, and validation path. For ecosystem partners, it creates a bridge between regional agriculture and digital infrastructure. For investors, it shows how agricultural deals can become easier to review, monitor, and discuss before any production investment claims are made.

The current goal is structured feedback. AgriPartners is ready to use the Alpha v1 demo to validate the story, improve materials, identify technical and partnership gaps, and prepare the next execution phase responsibly.
