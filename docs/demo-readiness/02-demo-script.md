# Demo Script

## Purpose

This script supports three demo lengths for investors, accelerators, and NEAR ecosystem partners.

## 3-Minute Version

### Opening

AgriPartners is an agricultural investment platform that helps investors review pilot deals, track farmer updates, and monitor projected returns.

### Flow

1. Start at Investor Login.
2. Open Investor Dashboard.
3. Highlight the two pilot profiles: Hissar Sheep as active and Fidlot as completed.
4. Open Hissar Sheep and show the active deal, farmer report, and returns view.
5. Open Fidlot and show completed status, returned amount, outstanding return, and ROI summary.
6. Briefly open Admin Dashboard to show operational oversight.

### Audience Emphasis

Investors:

- Clear deal-level return visibility.
- Completed pilot evidence.
- Simple summary of projected and returned capital.

Accelerators:

- MVP is demoable and structured.
- Pilot data is clean and repeatable.
- Roadmap can expand toward partnerships and program applications.

NEAR ecosystem partners:

- NEAR wallet and ecosystem alignment.
- Clear future path for deeper on-chain workflows.
- Practical real-world asset use case.

### Close

The Alpha v1 demo is designed to show that AgriPartners can present agricultural investment activity clearly, transparently, and in a way that is ready for ecosystem feedback.

## 5-Minute Version

### Opening

AgriPartners Alpha v1 focuses on one core question: can agricultural pilot deals be presented to investors with enough clarity to support feedback, validation, and partnership conversations?

### Flow

1. Investor Login: show access into the investor experience.
2. Investor Dashboard: explain active and completed pilot structure.
3. Active Deal (Hissar Sheep): show funding, projected ROI, farmer report, and current return state.
4. Farmer Report: explain operational reporting and investor transparency.
5. Returns View: show how returns are visible and how projected returns are framed as estimates.
6. Completed Deal (Fidlot): show returned amount, outstanding return, completed status, and ROI summary.
7. Admin Dashboard: show return summary, returns ledger, and record return workflow.

### Audience Emphasis

Investors:

- Focus on risk visibility, return status, and deal-level reporting.

Accelerators:

- Focus on MVP completeness, repeatable demo flow, and user clarity.

NEAR ecosystem partners:

- Focus on wallet readiness, ecosystem relevance, and future smart contract expansion.

### Close

The MVP is intentionally narrow: it demonstrates investor reporting, farmer updates, return visibility, and admin oversight without overpromising automated financial execution.

## 10-Minute Version

### Opening

AgriPartners is building a bridge between agricultural operators and investors. Alpha v1 demonstrates the reporting and operational layer needed before scaling to deeper automation.

### Flow

1. Investor Login: explain investor-first demo framing.
2. Investor Dashboard: walk through portfolio metrics, active deals, completed deals, projected returns, returned amount, and outstanding amount.
3. Active Deal (Hissar Sheep): explain why the active pilot matters and how investors review in-progress operations.
4. Farmer Report: read the report and connect it to real-world agricultural transparency.
5. Returns View: explain no-return or partial-return states and the non-guaranteed projection disclaimer.
6. Completed Deal (Fidlot): show the completed pilot and explain why it is the proof point.
7. ROI Summary: show projected ROI, projected return, returned amount, outstanding return, and completed return status.
8. Admin Dashboard: show return summary, returns ledger, farmer cycle status, and the existing record return workflow.
9. Positioning: explain how this demo supports investor validation, accelerator applications, and NEAR ecosystem conversations.

### Audience Emphasis

Investors:

- Deal-level summaries reduce ambiguity.
- Reports make operations easier to evaluate.
- Completed Fidlot data demonstrates the intended end state.

Accelerators:

- MVP has a clear user journey.
- Demo data is controlled and presentation-ready.
- Next steps can focus on validation, onboarding, and partnerships.

NEAR ecosystem partners:

- The product has a practical real-world asset narrative.
- Wallet login and future contract integration align with ecosystem priorities.
- The MVP can become a stronger showcase with more on-chain events and verified partner workflows.

### Close

AgriPartners Alpha v1 is ready for structured feedback. The next goal is to use this demo to validate investor understanding, partner interest, and ecosystem fit.
