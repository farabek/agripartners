# Demo Checklist

## Purpose

This checklist prepares AgriPartners Alpha v1 before investor, accelerator, partner, or NEAR ecosystem presentations.

## Before Presentation

### Runtime

- Backend running
- Frontend running
- Database migrated
- Environment variables checked
- API base URL confirmed

### Accounts

- Investor account ready
- Admin account ready
- Wallet login tested
- Password login tested if used
- Browser session reset or prepared

### Demo Data

- Fidlot Pilot visible as completed deal
- Fidlot returned amount visible
- Fidlot outstanding return is `$0`
- Fidlot return status shows Completed or Return Recorded
- Hissar Sheep Pilot visible as active deal
- Hissar farmer report visible
- Hissar returns view checked

### Materials

- Investor Deck available
- Screenshots available
- Demo script available
- Demo data pack available
- Product roadmap available if requested

### Technical Check

- Internet connection checked
- NEAR wallet page accessible
- Backend health checked
- Frontend page loads without console-blocking errors
- Test account credentials available to presenter
- Backup screenshots available if live demo fails

### Presentation Flow

- Investor Login tested
- Investor Dashboard tested
- Active Deal (Hissar Sheep) tested
- Farmer Report tested
- Returns View tested
- Completed Deal (Fidlot) tested
- ROI Summary tested
- Admin Dashboard tested

## Go / No-Go

Go if:

- Backend and frontend are reachable.
- Investor and admin accounts are ready.
- Fidlot completed deal shows correct returned amount and status.
- Hissar active deal shows report and return state.
- Screenshots are available as fallback.

No-go if:

- Login is blocked.
- Demo data is missing.
- Fidlot shows `No returns`.
- Admin Dashboard cannot load.
- Internet connection is unstable and no screenshot fallback is ready.

## Recommended Final Check

Run the full walkthrough once before the meeting and keep the 3-minute script open as a presenter fallback.
