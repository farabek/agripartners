# Demo Data Pack

## Purpose

This data pack documents the pilot entities used in AgriPartners Alpha v1 demonstrations.

## Completed Deal: Fidlot Pilot

### Summary

Fidlot Pilot is the completed deal used to demonstrate the full investor flow from funded pilot to recorded return.

### Funding

- Demo funding: `$50,000`
- Deal state: Completed
- Purpose: livestock fattening pilot profile

### ROI

- ROI shown in demo: `64%`
- Projected return shown in demo: `$82,000`
- Returned amount shown in demo: `$82,000`
- Outstanding return shown in demo: `$0`

### Return Status

- Expected status: Completed
- Acceptable demo wording: Completed or Return Recorded
- Should not show: No returns

### Reports Available

- Farmer report available
- Report status: submitted / completed pilot report
- Report purpose: show operational progress and investor-facing transparency

### Events Available

- Funding event
- Farmer report event
- Return recorded event
- Completed event

### Demo Role

Use Fidlot to show proof that the MVP can represent a completed agricultural investment cycle.
