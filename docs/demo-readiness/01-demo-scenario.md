# Demo Scenario

## Purpose

This scenario prepares AgriPartners Alpha v1 for investor, partner, accelerator, and NEAR ecosystem demonstrations.

## Walkthrough Flow

Investor Login -> Investor Dashboard -> Active Deal (Hissar Sheep) -> Farmer Report -> Returns View -> Completed Deal (Fidlot) -> ROI Summary -> Admin Dashboard

## Screen Sequence

### 1. Investor Login

Estimated timing: 20-30 seconds

Talking points:

- AgriPartners supports a dedicated investor experience.
- The demo starts from the investor point of view because investor clarity is the main MVP objective.
- Wallet and account-based access can be positioned as part of NEAR ecosystem readiness.

### 2. Investor Dashboard

Estimated timing: 30-45 seconds

Talking points:

- The dashboard summarizes active and completed pilot deals.
- Investors can see capital allocation, projected returns, returned amount, outstanding amount, and deal status.
- The dashboard is designed for quick review before opening deal-level details.

### 3. Active Deal: Hissar Sheep Pilot

Estimated timing: 45-60 seconds

Talking points:

- Hissar Sheep is the active pilot profile.
- The deal is still in progress, so return status should show no completed return yet.
- This screen demonstrates how an investor tracks an active agricultural project.

### 4. Farmer Report

Estimated timing: 45-60 seconds

Talking points:

- Farmer reports give investors operational context beyond financial numbers.
- Reports help connect on-chain deal tracking with real-world agricultural progress.
- This is useful for investors, accelerators, and ecosystem partners evaluating transparency.

### 5. Returns View

Estimated timing: 30-45 seconds

Talking points:

- The returns view shows whether repayments have been recorded.
- The MVP separates return ledger visibility from smart contract transfer execution.
- Projected returns are estimates and are not guaranteed.

### 6. Completed Deal: Fidlot Pilot

Estimated timing: 45-60 seconds

Talking points:

- Fidlot is the completed pilot profile.
- It demonstrates the completed flow from funding through recorded return.
- The completed deal is the strongest proof point for the demo.

### 7. ROI Summary

Estimated timing: 45-60 seconds

Talking points:

- ROI is calculated at deal level using projected ROI.
- The summary shows projected return, returned amount, outstanding return, and return status.
- Completed deals should show return status as Completed when returned amount meets or exceeds projected return.

### 8. Admin Dashboard

Estimated timing: 60-90 seconds

Talking points:

- Admin users can review deal operations, farmer cycle status, return summary, and returns ledger.
- Record Return remains a ledger action in the MVP.
- Admin view demonstrates operational readiness for a managed pilot program.

## Recommended Timing

Short walkthrough: 3 minutes

Standard walkthrough: 5 minutes

Full walkthrough with discussion: 10 minutes

## Demo Close

Close with three points:

- AgriPartners connects agricultural pilot funding with transparent investor reporting.
- NEAR provides a credible technical foundation for wallet access and future on-chain workflows.
- The Alpha v1 demo is ready for feedback from investors, accelerators, partners, and ecosystem teams.
