- Deal state: Completed
- Purpose: livestock fattening pilot profile

- Projected return shown in demo: `$82,000`
- Returned amount shown in demo: `$82,000`
- Outstanding return shown in demo: `$0`

### Reports Available

- Farmer report available

- Report purpose: показать operational progress и investor-facing transparency

### Events Available

### Demo Role

Использовать Fidlot, чтобы показать, что MVP может представлять completed agricultural investment cycle.
